# Blinkit Grocery Data Analysis Dashboard 📊

## 📌 Project Overview

This project is an interactive **Blinkit Grocery Data Analysis Dashboard** created using Microsoft Excel.

The dashboard helps analyze grocery sales performance based on different **outlet types, outlet sizes, outlet locations, item types, fat content, sales, ratings, and number of items**.

The main purpose of this project is to convert raw grocery data into an easy-to-understand interactive dashboard.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPIs
- Data Cleaning
- Data Visualization
- Dashboard Design

---

## 📊 Key KPIs

The dashboard displays the following key performance indicators:

- **Total Sales:** $1.20M
- **Average Sales:** $141
- **Number of Items:** 8,523
- **Average Rating:** 4.0

---

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Outlet Type
- Sales by Item Type
- Fat Content Analysis
- Fat Content by Outlet
- Outlet Establishment Trends
- Number of Items by Outlet Location

---

## 🎛️ Interactive Filters

Users can interact with the dashboard using slicers for:

- Outlet Size
- Outlet Location
- Item Type

These filters allow users to analyze specific segments of the grocery sales data.

---

## 🎯 Project Objective

The objective of this project is to:

- Analyze grocery sales data
- Identify sales trends
- Compare outlet performance
- Understand customer and product patterns
- Create an interactive business dashboard
- Present data in a clear and visual format
